PagePith gives your applications and AI tools readable content and brand context from public URLs. Use the REST API for application workflows or connect the remote MCP server to an AI client.

## Choose an interface

<Tabs>
  <Tab title="REST API">
    Send authenticated requests to `https://api.pagepith.com`. Start with the [quickstart](/quickstart), then explore the [API reference](/api-reference/overview).
  </Tab>
  <Tab title="MCP">
    Connect `https://mcp.pagepith.com/mcp` to an MCP client. The server exposes tools for reading URLs and processing video.
  </Tab>
</Tabs>

<Info>
  PagePith works with public company websites, JavaScript-rendered pages, PDFs, and public YouTube, Instagram, and TikTok videos. Pages behind a login are not supported.
</Info>
