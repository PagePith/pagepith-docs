PagePith exposes a JSON REST API at `https://api.pagepith.com`. All customer endpoints use HTTPS and JSON.

## Base URL

```text
https://api.pagepith.com
```

## Authentication

Send your API key as a Bearer token.

```http
Authorization: Bearer pp_live_your_key
```

See [Authentication](/authentication) for key management and error behavior.

## Usage

A successful synchronous or asynchronous page scrape consumes one credit. A successful brand profile consumes five credits. Native video captions consume one credit. Generated video transcripts consume four credits per rounded-up audio minute.
